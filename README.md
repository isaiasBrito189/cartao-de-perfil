# 💳 Cartão de Perfil

Um cartão de perfil desenvolvido com **HTML e CSS** como parte dos meus estudos em desenvolvimento web.

O projeto apresenta informações pessoais, tecnologias que estudo e um link para o meu GitHub, utilizando um design simples, moderno e responsivo.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* Flexbox
* Google Fonts

## 📸 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar:

* Estruturação de páginas com HTML
* Estilização com CSS
* Flexbox
* Responsividade
* Uso de fontes externas
* Efeitos de interação com `:hover`

## 🎯 Objetivo

Colocar em prática os conhecimentos adquiridos durante meus estudos de HTML e CSS e continuar evoluindo no desenvolvimento web.
